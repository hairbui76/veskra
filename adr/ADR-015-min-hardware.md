# ADR-015: Minimum hardware specification
Status: Proposed (blocked)
Date: 2026-10-09
Owner: QAP + AND
Related tickets: SPK-12, QAP-06, INT-05

## Context
Requires measured data from at least two physical tablet GPU/vendor families (MASTER_PLAN §1.3).
None is available in this environment.

## Decision
None yet. Provisional engineering assumption for memory budgets: ≥ 4 GB RAM device class, 2048–4096 px
canvases. This is not a published requirement.

## Acceptance experiment
SPK-12 device matrix + PERF-001..005 on real hardware.
