## New in this build
- **Check for updates from inside the app.** In the ⋯ menu, or next to the version under the gallery. Veskra downloads the new version from veskra.hairbui76.id.vn, checks its size and SHA-256, and asks Android to install it over the old one. Your drawings and brushes stay.
- The first time, Android asks you to allow "Install unknown apps" for Veskra (once).
- An open drawing is kept as a recovery copy while the update installs.

**Privacy:** Veskra now has the internet permission, used only when you tap *Check for updates* (it fetches one small file and the APK). Nothing about your drawings is sent anywhere. See [ADR-020](https://github.com/hairbui76/veskra/blob/main/adr/ADR-020-in-app-update.md).

**Install this build by hand once** (copies older than alpha.5 have no update button). After that, updates come from the app.

## Which APK to install

| File | For |
|---|---|
| `veskra-0.1.0-alpha.5-arm64-v8a.apk` | Real Android tablets and phones |
| `veskra-0.1.0-alpha.5-x86_64.apk` | Android emulator on a PC |
| `veskra-0.1.0-alpha.5-universal.apk` | Either |

Same signing key as earlier builds, so it installs over them and keeps your drawings.

**Pre-release for testing.** Tested on an Android tablet emulator only (no real tablet or stylus yet). Everything from earlier alphas is still here: 70 brushes with picture previews, brush editor, Infinite Painter brush import, CMYK print export, and the letter in the ⋯ menu.
